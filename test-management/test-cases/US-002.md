| Priority       | High                                                                                                          |
| Labels         | regression, positive, US-002                                                                                  |
| Status         | Automated                                                                                                     |
| Automated test | P02 CreateToken, N01 CreateToken ([source](../../postman/collections/restful-booker.postman_collection.json)) |
| Known defect   | -                                                                                                             |

| #   | Step             | Test data                                                                                                        | Expected result                                |
| --- | ---------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
