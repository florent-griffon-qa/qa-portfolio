# US-001 - Create and find a booking - test cases

Story: [US-001](../stories/US-001-create-booking.md). Format and lifecycle: [README](../README.md).

## QAP-T1 - Create a booking with valid data

| Field          | Value                                                                                                             |
| -------------- | ----------------------------------------------------------------------------------------------------------------- |
| Objective      | Check that a booking with all required fields is created and returned with its id.                                |
| Precondition   | The Restful-Booker API is reachable (local Docker instance or public instance).                                   |
| Priority       | High                                                                                                              |
| Labels         | regression, positive, US-001                                                                                      |
| Status         | Automated                                                                                                         |
| Automated test | P03 CreateBooking, N02 CreateBooking ([source](../../postman/collections/restful-booker.postman_collection.json)) |
| Known defect   | -                                                                                                                 |

| #   | Step                | Test data                                                                                                                                                                                                                                                 | Expected result                                                                                         |
| --- | ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 1   | Send POST /booking. | Headers: Content-Type: application/json, Accept: application/json. Body: firstname "Jim", lastname "Brown", totalprice 111, depositpaid true, checkin "2026-01-01", checkout "2026-01-02", additionalneeds "<request> - qa-portfolio run <YYMMDD_HHMMSS>" | Status 200. bookingid is a positive integer. booking echoes every field sent, additionalneeds included. |

## QAP-T2 - Read a booking by id

| Field          | Value                                                                                                                             |

| Priority       | High                                                                                                                              |
| Labels         | regression, positive, US-001                                                                                                      |
| Status         | Automated                                                                                                                         |

| Known defect   | -                                                                                                                                 |

| #   | Step                           | Test data                        | Expected result                                                                                          |
| --- | ------------------------------ | -------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 1   | Send GET /booking/{bookingid}. | Header: Accept: application/json | Status 200. firstname, lastname, totalprice, depositpaid, checkin and checkout equal the created values. |
